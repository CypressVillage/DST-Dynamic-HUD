# [DST] Dynamic HUD

本模组允许你根据所在区域或快捷键切换 HUD 主题。

github: [CypressVillage/DST-Dynamic-HUD](https://github.com/CypressVillage/DST-Dynamic-HUD)

## 功能

- 为默认区域、船上、洞穴和启蒙区域分别设置 HUD，并在区域变化时自动切换
- 通过可配置的快捷键，在原版 HUD 和已启用的受支持 HUD 之间循环切换
- 可配置区域优先级（设为 0 表示不启用）和切换过渡动画

## 注意事项

> [!WARNING]
> 切换到第三方 HUD 前，必须同时启用对应的 HUD 模组；原版 HUD 无需另装模组。
